# Vite & Gourmand

Application web de commande de menus pour le traiteur Vite & Gourmand.

## Stack technique

- Symfony 7.4 LTS
- PHP 8.4
- Nginx
- MySQL 8.4
- MongoDB 8.0
- Docker Compose
- Twig, Bootstrap and JavaScript

## Prérequis

- Git
- Docker Desktop with Docker Compose
